# WebAPI测试工具LRC文件处理功能改进

## 问题描述

在使用WebAPI测试工具的唱歌功能时，用户上传了LRC歌词文件，但服务器提示找不到对应的歌词文件：

```
使用文件: 《中华人民共和国国歌》官方录音版本（管弦乐版）.wav
LRC歌词文件: 歌词.lrc
歌词内容长度: 241 字符

=== 测试歌词API (/api/lyrics) ===
🔍 音频Hash: dae5c03e
⚠️ 歌词API状态: 成功 - 但未找到对应歌词文件
   预期文件: lyrics/dae5c03e.lrc 或 lrc/dae5c03e.lrc
```

## 根本原因

歌词API通过计算音频文件的MD5哈希值来搜索对应的LRC文件。用户上传的LRC文件名为`歌词.lrc`，但系统期望的文件名应该是基于音频hash的，如`lyrics/dae5c03e.lrc`。

原来的测试工具只是读取了LRC文件内容，但没有将其放置到正确的位置供歌词API搜索。

## 解决方案

### 1. 修改唱歌测试功能

在`test_singing_api`方法中添加了LRC文件处理逻辑：

- **计算音频Hash**: 使用MD5计算音频base64的哈希值
- **自动复制LRC文件**: 将用户选择的LRC文件复制到`lyrics/{hash}.lrc`位置
- **自动清理**: 测试完成后自动删除临时创建的LRC文件

```python
# 计算音频hash并复制LRC文件到正确位置
import hashlib
audio_hash = hashlib.md5(audio_base64.encode()).hexdigest()[:8]

# 确保lyrics目录存在
os.makedirs('lyrics', exist_ok=True)

# 复制LRC文件到正确位置
target_lrc_path = f"lyrics/{audio_hash}.lrc"
shutil.copy2(self.lrc_file_path, target_lrc_path)
```

### 2. 增强歌词测试功能

在歌词测试标签页中添加了LRC文件上传功能：

- **新增LRC文件选择**: 用户可以上传LRC文件进行测试
- **自动文件匹配**: 系统自动将LRC文件命名为正确的hash格式
- **实时反馈**: 显示文件处理过程和结果

### 3. 改进的用户体验

现在的工作流程：

1. **用户选择音频文件**
2. **用户选择LRC文件** (可选)
3. **系统计算音频Hash**: `dae5c03e`
4. **系统自动处理**: 将LRC文件复制为`lyrics/dae5c03e.lrc`
5. **测试歌词API**: 现在能成功找到对应的歌词文件
6. **测试唱歌API**: 唱歌时会正确显示LRC歌词
7. **自动清理**: 测试完成后删除临时文件

## 使用方法

### 唱歌测试 + LRC歌词

1. 切换到"唱歌测试"标签页
2. 选择音频文件或生成测试音频
3. 在"LRC歌词文件选择"区域选择LRC文件
4. 确保"启用字幕"已勾选
5. 点击"发送唱歌请求"

系统会：
- 自动计算音频hash
- 将LRC文件复制到正确位置
- 测试歌词API (应该能找到歌词)
- 测试唱歌API (会显示LRC歌词)
- 自动清理临时文件

### 单独的歌词测试

1. 切换到"歌词测试"标签页
2. 选择音频文件或生成测试音频
3. 在"LRC歌词文件上传"区域选择LRC文件
4. 点击"发送歌词请求"

系统会：
- 自动将LRC文件复制到对应hash位置
- 测试歌词API获取功能
- 显示找到的歌词内容
- 自动清理临时文件

## 技术细节

- **Hash算法**: MD5，取前8位作为文件名
- **文件编码**: UTF-8
- **搜索路径**: `lyrics/{hash}.lrc` 和 `lrc/{hash}.lrc`
- **自动清理**: 测试完成后删除临时文件和空目录
- **错误处理**: 完善的异常捕获和用户提示
