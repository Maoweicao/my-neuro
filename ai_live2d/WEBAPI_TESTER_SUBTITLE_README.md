# WebAPI Tester 字幕功能更新

## 🎉 新增功能

WebAPI Tester 现在支持测试唱歌时的字幕显示功能！

### ✅ 新功能列表

1. **字幕开关控制**
   - 在唱歌测试标签页中添加了"启用字幕"复选框
   - 可以控制是否在唱歌时显示字幕

2. **LRC歌词文件支持**
   - 支持选择LRC格式的歌词文件
   - 自动解析和显示歌词内容
   - 提供清除LRC文件的功能

3. **智能字幕显示**
   - **有LRC文件时**: 显示歌词内容
   - **无LRC文件时**: 显示 "♪ 唱歌中 ♫"
   - **字幕关闭时**: 不显示任何字幕

4. **增强的批量测试**
   - 批量测试现在包含两种模式：
     - 无字幕唱歌测试
     - 有字幕唱歌测试（无LRC文件）

## 📋 使用指南

### 1. 启动测试工具

```bash
python webapi_tester.py
```

### 2. 进入唱歌测试

1. 打开WebAPI Tester界面
2. 点击"唱歌测试"标签页

### 3. 配置测试参数

#### 基本参数
- **音量**: 0.0-2.0 (默认0.8)
- **循环播放**: 是否循环播放音频
- **Live2D动作**: 选择播放时的动作
- **启用字幕**: 控制是否显示字幕

#### 音频源选择
- **选择音频文件**: 从本地选择音频文件
- **生成测试音频**: 自动生成1秒的测试音频

#### LRC歌词文件（可选）
- **选择LRC文件**: 选择包含歌词的.lrc文件
- **清除LRC**: 清除已选择的LRC文件

### 4. 执行测试

1. 配置完参数后，点击"发送唱歌请求"
2. 观察结果显示区域的输出信息
3. 检查字幕是否按预期显示

## 🎵 字幕显示逻辑

| 字幕开关 | LRC文件 | 显示内容 |
|---------|---------|---------|
| ✅ 开启 | ✅ 有文件 | 显示LRC歌词内容 |
| ✅ 开启 | ❌ 无文件 | 显示 "♪ 唱歌中 ♫" |
| ❌ 关闭 | 任意 | 不显示字幕 |

## 📄 LRC文件格式

LRC文件格式示例：
```
[00:00.00]♪ 歌词第一行 ♪
[00:03.50]歌词第二行
[00:07.00]♪ 歌词第三行 ♪
[00:10.50]歌词第四行
```

- 时间格式: [分:秒.毫秒]
- 支持中文和特殊字符
- 空行会被自动跳过

## 🔄 批量测试

批量测试现在包含两个唱歌测试场景：

1. **无字幕测试**: 验证基本唱歌功能
2. **有字幕测试**: 验证字幕显示功能（显示 ♪ 唱歌中 ♫）

## 🧪 测试验证

```bash
python test_subtitle_webapi.py
```

### 手动测试步骤
1. 启动 `main.py`
2. 启动 `webapi_tester.py`
3. 在唱歌测试中尝试以下组合：
   - 字幕开启 + 无LRC文件
   - 字幕开启 + 有LRC文件
   - 字幕关闭
4. 观察字幕显示是否正确

## ⚙️ 配置要求

确保 `config.json` 中字幕功能已启用：
```json
{
  "setting": {
    "subtitle_enabled": true
  }
}
```

## 🔧 技术实现

- **UI集成**: 在PyQt界面中添加字幕控制组件
- **文件处理**: 支持LRC文件的读取和解析
- **状态管理**: 实时显示当前字幕设置状态
- **错误处理**: 完善的异常处理和用户提示

## 📝 注意事项

1. LRC文件必须使用UTF-8编码
2. 音频文件大小影响请求超时时间
3. 字幕显示依赖于main.py中的字幕管理器
4. 批量测试会在两次请求之间暂停1秒
