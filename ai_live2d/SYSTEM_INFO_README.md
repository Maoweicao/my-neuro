# 系统信息显示功能说明

## 概述

为AI Live2D项目的UI.py添加了详细的系统信息显示功能，包括：

1. **设置页面中的系统信息显示**
2. **增强的日志收集功能**

## 新增功能

### 1. 设置页面系统信息组

在设置标签页中新增了"系统信息"组，显示以下信息：

#### 基本系统信息
- 操作系统版本
- 计算机名
- 处理器架构
- Python版本

#### CPU信息  
- 处理器型号
- 物理核心数/逻辑核心数
- CPU频率（当前/最大）
- CPU使用率

#### 内存信息
- 总内存/可用内存/已用内存
- 内存使用率
- 交换内存信息

#### 显卡信息 ⭐ 新增重点功能
- **NVIDIA GPU信息**：
  - GPU型号
  - 显存大小
  - 驱动版本
  - CUDA版本（通过nvidia-smi获取）
- **通用显卡信息**：
  - 通过Windows wmic命令获取所有显卡
  - 显示显卡名称和显存信息

#### CUDA信息 ⭐ 新增重点功能
- **NVCC版本**：通过nvcc --version获取
- **PyTorch CUDA支持**：
  - CUDA是否可用
  - PyTorch CUDA版本
  - 可用GPU数量和名称

#### 声卡信息 ⭐ 新增功能
- 通过Windows wmic sounddev命令获取
- 显示所有音频设备名称

#### 网络信息
- 主机名和本地IP
- 网络接口信息

#### 存储信息
- 各磁盘分区信息
- 磁盘使用率和可用空间

### 2. 增强的日志收集功能

更新了 `_collect_system_info()` 方法，在日志包中包含显卡信息：

- NVIDIA GPU详细信息
- 通用显卡信息
- CUDA环境检测
- PyTorch CUDA支持状态

## 使用方法

### 在UI中查看系统信息

1. 启动AI Live2D应用程序：
   ```bash
   python UI.py
   ```

2. 切换到"设置"标签页

3. 向下滚动找到"系统信息"组

4. 点击"刷新系统信息"按钮可更新信息

### 日志包中的系统信息

当点击"保存日志包"时，系统信息将自动包含在导出的ZIP文件中，方便技术支持和问题诊断。

## 技术特点

### 兼容性设计
- 自动检测psutil库是否可用
- 对于不同操作系统采用不同的信息获取方式
- 错误处理机制，避免因单项检测失败导致整体崩溃

### 性能优化
- 使用subprocess timeout避免命令执行超时
- 异常处理确保界面稳定性
- 信息缓存和按需刷新

### 用户体验
- 等宽字体显示，便于阅读
- 实时刷新功能
- 成功/失败状态提示

## 依赖要求

### 必需依赖
- PyQt5
- qfluentwidgets

### 可选依赖
- **psutil**：用于获取详细硬件信息
- **torch**：用于CUDA环境检测
- **nvidia-ml-py**：可进一步扩展GPU监控

### 系统要求
- **Windows系统**：完整支持所有功能
- **Linux/macOS**：支持基本功能，显卡和声卡信息获取有限

## 故障排除

### 常见问题

1. **显卡信息显示不完整**
   - 确保nvidia-smi在PATH中（NVIDIA用户）
   - Windows用户确保wmic命令可用

2. **CUDA信息显示"不可用"**
   - 检查NVIDIA驱动是否正确安装
   - 确认PyTorch安装了CUDA版本

3. **部分信息显示"权限不足"**
   - 以管理员权限运行应用程序

4. **psutil相关错误**
   - 安装psutil：`pip install psutil`
