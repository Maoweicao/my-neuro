# 动作按钮功能

## 概述

新增了动作按钮功能，包括打断、动作一和动作二三个按钮，可以在Live2D动画操控界面中使用，并支持在UI设置中进行开关控制和动作绑定配置。

## 新增功能

### 1. 动作按钮开关
- **位置**: 设置标签页 → 项目设置
- **功能**: 控制动作按钮的显示/隐藏
- **默认值**: 启用

### 2. 动作按钮
在动画操控标签页的快捷操控组中新增了三个按钮：

#### 打断按钮
- **图标**: 停止图标
- **功能**: 打断当前AI输出和语音播放
- **快捷键**: 无
- **关联功能**: 调用 `interrupt_current_operations()` 方法

#### 动作一按钮
- **图标**: 播放图标
- **功能**: 播放绑定的动作一
- **快捷键**: 无
- **绑定方式**: 在Live2D标签页中设置

#### 动作二按钮
- **图标**: 播放图标
- **功能**: 播放绑定的动作二
- **快捷键**: 无
- **绑定方式**: 在Live2D标签页中设置

### 3. 动作绑定设置
- **位置**: Live2D标签页 → 动作按钮绑定设置
- **功能**: 为动作一和动作二按钮绑定特定的Live2D动作
- **操作方式**:
  1. 从下拉列表中选择要绑定的动作
  2. 点击对应的"绑定"按钮
  3. 绑定信息会保存到配置文件

## 配置说明

### 配置文件结构

```json
{
  "setting": {
    "action_buttons_enabled": true
  },
  "action_buttons": {
    "action_1": "Idle",
    "action_2": "Tap"
  }
}
```

### 配置项说明

- `setting.action_buttons_enabled`: 动作按钮开关，控制按钮显示/隐藏
- `action_buttons.action_1`: 动作一绑定的动作名称
- `action_buttons.action_2`: 动作二绑定的动作名称

## 使用方法

### 1. 启用功能
1. 打开UI设置
2. 进入"设置"标签页
3. 确保"动作按钮开关"已启用

### 2. 绑定动作
1. 进入"Live2D"标签页
2. 在"动作按钮绑定设置"组中：
   - 为动作一选择要绑定的动作，点击"绑定"
   - 为动作二选择要绑定的动作，点击"绑定"
3. 绑定状态会显示在状态浏览器中

### 3. 使用按钮
1. 进入"动画操控"标签页
2. 在快捷操控组中可以看到三个新按钮：
   - **打断**: 停止当前AI输出和语音
   - **动作一**: 播放绑定的动作一
   - **动作二**: 播放绑定的动作二

## 注意事项

1. **开关控制**: 只有在开关启用时，动作按钮才会显示
2. **动作绑定**: 如果没有绑定动作，按钮会播放默认动作
3. **Live2D依赖**: 动作播放依赖于Live2D模型的支持
4. **配置保存**: 所有设置会自动保存到config.json文件中

## 故障排除

### 按钮不显示
- 检查"动作按钮开关"是否启用
- 重新启动UI应用

### 动作播放失败
- 检查Live2D模型是否正确加载
- 确认绑定的动作是否存在
- 查看控制台错误信息

### 绑定设置不生效
- 确保点击了"绑定"按钮
- 检查配置文件权限
- 重新加载UI配置
