# 日志管理功能使用说明

## 功能概述

在AI Live2D项目的设置页面中新增了**日志管理**功能，提供了日志的保存、清空和查看等操作。

## 功能特性

### 1. 日志状态显示
- 实时显示日志文件的数量和总大小
- 自动格式化文件大小显示（B/KB/MB）
- 状态异常时会显示错误提示

### 2. 保存日志包功能
- **功能**：将所有日志文件、配置文件和系统信息打包成ZIP文件
- **包含内容**：
  - 所有logs目录下的.log文件
  - config.json和config_example.json配置文件
  - chat_log.txt和pet_system.log文件
  - 自动生成的系统信息文件（system_info.txt）
  - 自动生成的运行时信息文件（runtime_info.txt）

#### 系统信息内容：
- 操作系统信息（版本、架构等）
- 硬件信息（CPU、内存、磁盘）
- 网络信息（主机名、IP地址）
- Python环境信息

#### 运行时信息内容：
- 当前配置摘要（LLM、TTS、ASR、WebAPI状态）
- 进程信息（PID、内存使用、CPU使用率）
- 重要环境变量
- 收集时间戳

### 3. 清空日志功能
- **功能**：清空所有日志文件的内容（保留文件结构）
- **安全性**：包含确认对话框，防止误操作
- **清空范围**：
  - logs/llm_interactions.log
  - logs/asr_interactions.log
  - logs/tts_interactions.log
  - logs/webapi_interactions.log
  - chat_log.txt
  - pet_system.log

### 4. 查看日志目录功能
- **功能**：在系统文件管理器中打开logs目录
- **跨平台**：支持Windows、macOS、Linux
- **智能创建**：如果目录不存在会自动创建

## 使用方法

1. **启动应用**：运行AI Live2D应用
2. **进入设置页面**：点击导航栏的"设置"选项
3. **找到日志管理区域**：滚动到页面底部找到"日志管理"分组
4. **查看状态**：观察"日志文件状态"显示的文件数量和大小
5. **执行操作**：
   - 点击"保存日志包"：选择保存位置，生成ZIP文件
   - 点击"清空日志"：确认后清空所有日志内容
   - 点击"查看日志目录"：在文件管理器中打开logs文件夹

## 按钮样式

- **保存日志包**：蓝色按钮（#0078d4）
- **清空日志**：红色按钮（#d83b01）
- **查看日志目录**：默认样式

## 错误处理

- 所有操作都包含异常处理
- 操作结果会通过InfoBar组件显示给用户
- 错误信息会详细显示具体的失败原因

## 依赖项

- **基础依赖**：PyQt5、qfluentwidgets
- **可选依赖**：psutil（用于详细硬件信息收集，如果未安装会降级收集基础信息）
- **系统依赖**：zipfile（Python标准库）

## 文件结构

保存的日志包结构示例：
```
ai_live2d_logs_20240904_143022.zip
├── logs/
│   ├── llm_interactions.log
│   ├── asr_interactions.log
│   ├── tts_interactions.log
│   └── webapi_interactions.log
├── config.json
├── config_example.json
├── chat_log.txt
├── pet_system.log
├── system_info.txt
└── runtime_info.txt
```

## 注意事项

1. **文件大小**：日志文件可能会很大，建议定期清理
2. **隐私保护**：日志包可能包含敏感信息，请谨慎分享
3. **存储空间**：确保有足够的磁盘空间来保存日志包
4. **权限问题**：确保应用有读写日志目录的权限

## 故障排除

### 问题：无法保存日志包
- 检查目标目录是否有写入权限
- 确保磁盘空间充足
- 检查文件是否被其他程序占用

### 问题：清空日志失败
- 检查日志文件是否被其他程序打开
- 确保有写入权限
- 重启应用后重试

### 问题：无法打开日志目录
- 检查logs目录是否存在
- 确认系统支持的文件管理器
- 手动导航到应用目录下的logs文件夹
