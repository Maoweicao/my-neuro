# 多显示器字幕功能实现总结

## 功能概述

为AI Live2D桌面宠物的字幕系统添加了完整的多显示器支持功能，用户现在可以：

1. **选择目标显示器** - 在多显示器环境中选择字幕显示的屏幕
2. **自定义显示位置** - 支持7种预设位置：居中、顶部、底部、四个角落
3. **精确位置调整** - 通过X/Y偏移量进行像素级的位置微调
4. **实时配置更新** - 设置变更立即生效，无需重启应用

## 实现的文件修改

### 1. 用户界面 (`UI.py`)

**新增功能：**
- 在字幕设置选项卡中添加了"显示设置"分组
- 显示器选择下拉框，支持显示详细的显示器信息（名称、分辨率、主屏标识）
- 显示位置选择下拉框，提供7种预设位置选项
- X/Y偏移量调整控件，范围-3000到+3000像素
- 刷新显示器列表按钮

**配置字段更新：**
```json
{
  "subtitle": {
    "display_monitor": 0,      // 目标显示器索引
    "display_position": "center", // 显示位置
    "display_offset_x": 0,     // X轴偏移量
    "display_offset_y": 0      // Y轴偏移量
  }
}
```

**事件处理：**
- `on_monitor_selection_changed()` - 显示器选择变化处理
- `_on_subtitle_position_changed()` - 位置选择变化处理
- `_on_subtitle_offset_changed()` - 偏移量变化处理
- `_send_subtitle_display_update()` - 向main.py发送配置更新消息

### 2. 字幕管理器 (`interface/subtitle_manager.py`)

**核心功能增强：**
- 重构了 `_update_size_and_position()` 方法，分离窗口大小计算和位置设置
- 新增 `_set_window_position()` 方法，支持多显示器和多种位置模式
- 添加 `update_display_settings()` 方法，支持实时更新显示设置
- 新增 `get_monitor_info()` 方法，获取详细的显示器信息

**位置计算逻辑：**
```python
# 支持的位置模式
positions = {
    "center": 屏幕中央,
    "top": 屏幕上方居中,
    "bottom": 屏幕下方居中,
    "top_left": 左上角,
    "top_right": 右上角,
    "bottom_left": 左下角,
    "bottom_right": 右下角
}
```

**显示器检测：**
- 使用 `QGuiApplication.screens()` 获取详细屏幕信息
- 回退到 `QDesktopWidget` 确保兼容性
- 自动处理无效显示器索引

### 3. 主应用程序 (`main.py`)

**消息处理系统：**
- 注册新的消息处理器：`update_subtitle_display`
- 添加 `_handle_update_subtitle_display_message()` 方法
- 新增 `update_subtitle_display_settings()` 方法调用字幕管理器
- 添加 `get_subtitle_monitor_info()` 方法获取显示器信息

**通信流程：**
```
UI控件变化 → 消息队列 → main.py处理器 → 字幕管理器更新 → 实时重新定位
```

### 4. 配置文件 (`config.json`)

**新增配置项：**
```json
{
  "subtitle": {
    // ...existing fields...
    "display_monitor": 0,
    "display_position": "center", 
    "display_offset_x": 0,
    "display_offset_y": 0
  }
}
```

## 技术特性

### 显示器检测
- **高级检测**：优先使用 `QGuiApplication.screens()` 获取详细信息
- **兼容性**：回退到 `QDesktopWidget` 确保在所有环境下工作
- **信息丰富**：显示屏幕名称、分辨率、位置、主屏标识

### 位置计算
- **智能定位**：基于目标显示器的几何信息计算精确位置
- **偏移支持**：在预设位置基础上应用用户自定义偏移
- **边界处理**：自动处理显示器索引越界情况

### 实时更新
- **即时生效**：配置变更立即通过消息队列通知字幕管理器
- **线程安全**：使用Qt信号机制确保UI线程安全
- **配置持久化**：设置自动保存到config.json

### 错误处理
- **容错机制**：显示器不可用时自动回退到主显示器
- **异常捕获**：完整的try-catch覆盖，防止崩溃
- **日志记录**：详细的调试和错误日志

## 使用方法

1. **打开字幕设置**：在UI界面找到字幕选项卡
2. **选择显示器**：从"显示设置"组中选择目标显示器
3. **设置位置**：选择预设位置或使用偏移量微调
4. **实时预览**：设置变更立即在选中的显示器上生效
5. **保存配置**：设置自动保存，下次启动时恢复

## 测试验证

创建了完整的测试脚本验证功能：
- `test_multi_monitor.py` - 基础多显示器检测和窗口定位测试
- `test_subtitle_multi_monitor_integration.py` - 完整功能集成测试

## 兼容性说明

- **单显示器环境**：在单显示器环境下正常工作，显示器选择自动设为主屏
- **动态显示器**：支持显示器热插拔，可通过刷新按钮重新检测
- **分辨率变化**：自动适应显示器分辨率变化
- **操作系统**：支持Windows、Linux、macOS（通过PyQt5）

## 性能优化

- **懒加载**：只在需要时进行显示器检测
- **缓存机制**：避免重复的屏幕信息查询
- **异步更新**：配置更新不阻塞UI响应
- **资源清理**：及时释放不再使用的显示器资源
