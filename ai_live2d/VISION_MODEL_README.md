# AI Live2D 视觉模型集成指南

## 功能概述

现在你可以在AI Live2D系统中使用独立的视觉模型来处理图片识别，为不支持视觉功能的主LLM提供视觉能力。

## 配置说明

### 1. 基本配置

在UI的"大语言模型"标签页中找到"视觉模型配置"部分：

- **启用视觉模式**: 开启后才能使用视觉功能
- **视觉模型API Key**: 视觉模型的API密钥
- **视觉模型API URL**: 视觉模型的API地址
- **视觉模型**: 选择支持视觉的模型（如gpt-4-vision-preview、gpt-4o等）
- **视觉识别提示词**: 自定义提示词来指导AI如何分析图片
- **仅在主LLM不支持视觉时使用**: 建议开启，避免重复处理

### 2. 配置文件示例

```json
{
  "vision": {
    "enabled": true,
    "api_key": "your-vision-api-key",
    "api_url": "https://api.openai.com",
    "model": "gpt-4-vision-preview",
    "system_prompt": "请仔细观察这张图片，描述你看到的内容。重点关注图片中的文字、物体、人物、场景等关键信息。",
    "fallback_only": true
  }
}
```

## 使用方法

### 1. 通过UI测试

1. 在"大语言模型"标签页找到"视觉功能测试"部分
2. 复制图片到剪贴板（Ctrl+C复制图片）
3. 点击"测试视觉识别"按钮
4. 如果剪贴板没有图片，会弹出文件选择框
5. 查看识别结果

### 2. 通过WebAPI使用

发送POST请求到 `/chat` 端点：

```json
{
  "message": "这张图片里有什么？",
  "image_data": "base64编码的图片数据",
  "api_key": "your-api-key"
}
```

### 3. 工作流程

1. **图片检测**: 系统检测到有图片数据
2. **模型判断**: 检查主LLM是否支持视觉
3. **视觉处理**: 如果主LLM不支持或配置为使用独立视觉模型，则先进行视觉识别
4. **结果整合**: 将视觉识别结果作为上下文信息传递给主LLM
5. **最终响应**: 主LLM基于视觉识别结果和用户问题生成回答

## 配置建议

### 1. 提示词优化

根据你的使用场景自定义视觉识别提示词：

**通用场景**:
```
请仔细观察这张图片，描述你看到的内容。重点关注图片中的文字、物体、人物、场景等关键信息。
```

**文档识别**:
```
请识别图片中的所有文字内容，包括标题、正文、表格等，并保持原有的格式结构。
```

**物体检测**:
```
请详细列出图片中的所有物体，包括它们的位置、颜色、大小等特征。
```

### 2. 模型选择

- **精度优先**: 使用GPT-4 Vision Preview或Claude 3 Opus
- **速度优先**: 使用GPT-4o或较小的视觉模型
- **成本优先**: 使用开源的视觉模型或自部署方案

## 故障排除

### 常见问题

1. **配置不完整**
   - 检查API Key和URL是否正确填写
   - 确认视觉模式已启用

2. **图片格式问题**
   - 支持常见格式：JPG、PNG、BMP、GIF
   - 图片大小建议在20MB以内

3. **API调用失败**
   - 检查API Key是否有效
   - 确认网络连接正常
   - 查看错误日志获取详细信息

4. **识别结果不理想**
   - 优化视觉识别提示词
   - 尝试不同的视觉模型
   - 确保图片清晰度足够

### 日志查看

系统会记录视觉识别的相关日志：
- LLM交互日志中包含视觉处理信息
- 控制台输出视觉识别的执行状态
- WebAPI日志记录包含图片的请求

## 扩展功能

### 自定义处理逻辑

你可以在 `UI.py` 中的 `_process_vision_request` 方法中添加自定义的图片预处理逻辑：

```python
def _process_vision_request(self, image_data, vision_config):
    # 添加图片预处理
    processed_image = self.preprocess_image(image_data)
    
    # 调用视觉API
    result = self.call_vision_api(processed_image, vision_config)
    
    # 后处理结果
    return self.postprocess_result(result)
```

### 批量处理

对于需要处理多张图片的场景，可以扩展API支持图片数组：

```json
{
  "message": "比较这些图片的区别",
  "images": [
    "base64_image_1",
    "base64_image_2"
  ]
}
```

## 注意事项

1. **隐私保护**: 图片数据会发送到配置的视觉模型API，请注意隐私保护
2. **成本控制**: 视觉模型通常比文本模型更昂贵，请合理使用
3. **处理时间**: 图片处理需要额外时间，请耐心等待
4. **网络要求**: 需要稳定的网络连接来调用视觉API
