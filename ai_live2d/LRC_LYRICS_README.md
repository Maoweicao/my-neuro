# LRC歌词显示功能说明

## 功能概述

AI桌面宠物现在支持LRC格式歌词的时间同步显示！当播放音频时，系统会自动查找对应的LRC歌词文件，并按照时间轴实时显示歌词内容。

## 功能特性

✅ **自动LRC解析**: 支持标准LRC格式歌词文件  
✅ **时间同步显示**: 歌词按照时间轴精准显示  
✅ **多格式支持**: 支持中文、英文及混合歌词  
✅ **元数据识别**: 自动识别歌手、歌名、专辑等信息  
✅ **智能回退**: 无LRC文件时显示默认字幕  
✅ **中断控制**: 支持播放中断和停止  
✅ **跳转功能**: 支持时间点跳转（程序内部）  

## 使用方法

### 1. 启用字幕功能

在 `config.json` 中设置：
```json
{
  "setting": {
    "subtitle_enabled": true
  }
}
```

### 2. 准备LRC歌词文件

1. 创建 `lyrics/` 目录（如果不存在）
2. 将LRC歌词文件放入该目录
3. 文件命名格式：`{音频哈希}.lrc`

### 3. 获取音频哈希

音频哈希通过以下方式生成：
```python
import hashlib
import base64

# 将音频文件编码为base64
with open('your_audio.wav', 'rb') as f:
    audio_data = f.read()
audio_base64 = base64.b64encode(audio_data).decode('utf-8')

# 计算哈希（取前8位）
audio_hash = hashlib.md5(audio_base64.encode()).hexdigest()[:8]
print(f"音频哈希: {audio_hash}")
```

### 4. LRC文件格式

#### 标准LRC格式示例：
```lrc
[ar:歌手名称]
[ti:歌曲标题]
[al:专辑名称]
[by:LRC制作者]
[offset:0]

[00:00.00]第一句歌词
[00:05.50]第二句歌词
[00:10.30]这里是副歌部分
[00:15.80][00:45.20]重复的歌词（两个时间点）
[00:20.10]继续下一句
[00:25.60]
[00:30.40]空行表示间奏
[00:35.90]最后一句歌词
```

#### 时间格式说明：
- `[mm:ss.xx]` - 分:秒.百分秒（如 `[02:15.30]`）
- `[mm:ss.xxx]` - 分:秒.毫秒（如 `[02:15.300]`）
- 支持一行多个时间标签（表示重复歌词）

## API接口

### 唱歌API使用LRC
发送POST请求到 `/api/sing`：
```json
{
  "audio_data": "base64编码的音频数据",
  "volume": 1.0,
  "loop": false,
  "singing_motion": "唱歌"
}
```

系统会自动：
1. 计算音频数据的哈希值
2. 查找对应的LRC文件
3. 解析LRC内容
4. 在播放时显示同步歌词

## 故障排除

### 1. LRC文件未找到
- 检查文件路径：`lyrics/{音频哈希}.lrc`
- 确认文件名格式正确
- 验证文件编码为UTF-8

### 2. 歌词显示时间不对
- 检查LRC文件时间格式
- 确认offset设置
- 验证音频播放同步

### 3. 中文乱码
- 确保LRC文件使用UTF-8编码
- 检查系统字体支持

### 4. 字幕不显示
- 确认config.json中`subtitle_enabled`为true
- 检查字幕管理器是否初始化
- 查看日志中的错误信息

## 高级功能

### 1. 自定义LRC路径
支持多个查找路径：
- `lyrics/{hash}.lrc`
- `lyrics/audio_{hash}.lrc`
- `lrc/{hash}.lrc`
- `lrc/audio_{hash}.lrc`
- `{hash}.lrc`
- `audio_{hash}.lrc`

### 2. 元数据标签支持
- `[ar:歌手]` - 艺术家
- `[ti:标题]` - 歌曲标题
- `[al:专辑]` - 专辑名称
- `[by:制作者]` - LRC制作者
- `[offset:偏移]` - 时间偏移（毫秒）

### 3. 程序集成
在main.py中，LRC管理器会：
- 自动与字幕管理器集成
- 处理播放、暂停、停止事件
- 响应中断请求
- 提供播放状态查询

## 注意事项

1. **性能**: LRC文件应控制在合理大小内
2. **编码**: 务必使用UTF-8编码保存LRC文件
3. **同步**: 时间轴应与实际音频对应
4. **备用**: 无LRC文件时会显示默认字幕"♪ 唱歌中 ♫"
