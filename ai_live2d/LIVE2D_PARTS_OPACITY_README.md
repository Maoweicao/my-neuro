# Live2D部件透明度设置功能

## 功能概述

新增的Live2D部件透明度设置功能允许用户为Live2D模型的各个部件单独调整透明度，实现更精细的视觉效果控制。

## 主要特性

### 1. 自动部件检测
- 系统会自动检测当前加载的Live2D模型的所有可用部件
- 支持从Live2D模型实例直接获取部件信息
- 如果无法从模型获取，会尝试从model3.json文件解析
- 提供默认的常见部件列表作为fallback

### 2. 实时透明度控制
- 为每个检测到的部件提供独立的透明度滑块 (0-100%)
- 实时显示当前透明度数值
- 支持实时预览效果

### 3. 配置持久化
- 透明度设置自动保存到`config.json`文件的`live2d`节点下
- 按模型名称分别保存配置，支持多个模型的独立设置
- 配置结构示例：
```json
{
  "live2d": {
    "model_name": {
      "parts_opacity": {
        "body": 80,
        "head": 90,
        "face": 100,
        "eyes": 95
      }
    }
  }
}
```

### 4. 运行时应用
- 通过进程间通信将透明度设置实时应用到Live2D模型
- 支持多种Live2D SDK的透明度设置方法
- 提供错误处理和日志记录

## 使用方法

### 1. 打开动画控制标签页
启动应用程序后，点击"动画操控"标签页。

### 2. 检测Live2D部件
在"部件透明度设置"组中点击"检测部件"按钮，系统会：
- 自动检测当前Live2D模型的所有部件
- 为每个部件创建透明度控制滑块
- 显示检测到的部件数量

### 3. 调整透明度
- 使用滑块调整每个部件的透明度 (0-100%)
- 数值标签会实时显示当前设置的百分比
- 可以为不同部件设置不同的透明度值

### 4. 应用设置
点击"应用设置"按钮将透明度设置应用到Live2D模型：
- 设置会实时应用到正在显示的模型
- 配置自动保存到`config.json`
- 显示应用结果的提示信息

## 技术实现

### UI组件
- `detect_live2d_parts()`: 检测Live2D模型部件
- `_create_parts_opacity_controls()`: 创建透明度控制UI
- `apply_live2d_parts_opacity()`: 应用透明度设置
- `_update_live2d_parts_widgets()`: 更新控件显示值

### 后端处理
- `_handle_set_live2d_parts_opacity_message()`: 处理UI发送的消息
- `_apply_live2d_parts_opacity()`: 应用透明度到Live2D模型
- `_find_live2d_part_index()`: 查找部件索引

### 配置管理
- `collect_values()`: 收集透明度设置到配置
- `update_widgets()`: 从配置恢复透明度设置
- 支持按模型名称的独立配置存储

## 支持的部件类型

系统支持检测以下类型的部件：
- **纹理部件**: 从model3.json的Textures部分解析
- **动作部件**: 从model3.json的Motions部分解析
- **标准部件**: 身体、头部、脸部、眼睛、嘴巴、头发、衣服等
- **自定义部件**: Live2D SDK识别的任何部件

## 错误处理

系统提供完善的错误处理机制：
- 部件检测失败时的友好提示
- 透明度应用失败时的日志记录
- 配置保存失败时的用户通知
- 网络通信异常的自动重试

## 兼容性

- 支持多种Live2D SDK版本
- 兼容不同的Live2D模型格式
- 向后兼容现有的配置结构
- 支持模型切换时的配置自动加载

## 注意事项

1. 透明度设置仅在Live2D模型加载后生效
2. 不同模型的部件可能不同，建议为每个模型单独配置
3. 透明度值为0时部件完全透明，100时完全不透明
4. 设置会立即保存，无需手动保存配置
5. 如果检测失败，可以尝试重新加载Live2D模型
